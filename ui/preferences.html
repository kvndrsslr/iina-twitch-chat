twitch-tui configuration

Leave empty to search the places twitch-tui uses, in order: the TWT_CONFIG environment variable (see below), ~/.config/twt/config.toml (the XDG location), then ~/Library/Application Support/com.twitch-tui.twt/config.toml (what the directories crate derives from ProjectDirs::from("com", "twitch-tui", "twt") on macOS), then ~/Library/Preferences/com.twitch-tui.twt/config.toml. The filters.txt is read from the folder of the config file that was found, and the Status line below always names the file that was used (or every path tried). TWT_CONFIG is honoured only when it is present in IINA's own environment (for example when IINA was launched from a shell that exported it); exporting it in a shell profile after IINA started does not affect the running app.

Automatic joining

Detection trusts twitch.tv/<channel> URLs found in the video's URL, path, file name, media title or playlist entry, and only guesses from the title when the same media is demonstrably Twitch-sourced (so a YouTube video called Bob - highlights never joins #bob). With this switch on (the default), the plugin joins the channel of the playing video automatically. Turn it off and the plugin never joins automatically. Detection itself is always automatic: it runs on every file load.

Startup

When IINA launches with nothing playing, the standalone Twitch browser window opens by itself, once per launch. It waits a few seconds first: opening a stream or a file in that window (or IINA restoring the last one) cancels it, and a window that is already open is left alone. Opening it by hand (⌘⇧W) is unaffected.

Chat history

The plugin always keeps its own cache of the last 50 messages per channel (up to 20 channels, at most 512 KB) in its data folder, so a channel you return to is not empty. With this option on, a channel visited for the first time is pre-filled from recent-messages.robotty.de — that request carries only the public channel name, never your OAuth token. Twitch offers no chat-history API of its own.

While a Twitch VOD plays, the plugin fetches the chat that was posted during that broadcast and replays it in sync with the video. This uses Twitch's undocumented GQL endpoint — not an official API — so it may stop working if Twitch changes it. Live chat is hidden while a VOD is playing.

OAuth token (only needed to send messages)
unknown

The token is stored in the macOS Keychain and is only ever used for the IRC connection; it is never written to the twt config file. [twitch] token in the config file takes precedence. Chat is fully usable read-only without a token.

Chat appearance

Every control defaults to “Use config”; pick a value to override the twt config for this plugin. The same overrides are available from the Settings tab in the sidebar.

Filters
unknown

Patterns come from [filters] / filters.txt and are applied by twitch-tui's rules (regex, falling back to a case-insensitive substring match; reversed inverts the result). They cannot be edited here because the plugin only ever reads the config file.
